## Requirements and multiplayer

Use a lawfully obtained compatible game and the separately installed loader.
Back up saves before installation and follow the README's release requirements
and known issues. Compatibility, uninterrupted operation and save preservation
are not guaranteed. Package 0.2.8 updates documentation/branding; its
executable remains **v0.2.5 / protocol 111**, unchanged from the published DLL.
No Steam joining is added by this package.

Join only hosts you trust. The published DLL shares a name derived from the
Windows account username with the party; a TCP host sees connecting network
addresses, and participants retain local connection/session logs. Do not expose
the development control socket to the internet. Do not use the mod for
harassment, unauthorized access or service disruption.
